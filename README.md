# 🎯 Guess The Number (mini-game)

A simple, interactive number-guessing game built with **React** and **Vite**. The game generates a random 2-digit number between 10 and 99, and gives you 5 attempts to guess it.

---

## 🎮 How to Play

1. Click **Play** to generate a secret 2-digit number.
2. Enter your guess in the input box and click **Check**.
3. Follow the hints (_"Too high!"_ or _"Too low!"_) to adjust your next guess.
4. Win by guessing the correct number within **5 attempts**!

---

## 🚀 Tech Stack

- **Frontend Framework:** React
- **Build Tool:** Vite
- **Styling:** CSS3

---

## 💻 Local Setup & Installation

To run this project on your local machine:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/pawan244701/GuessTheNumber.git

    # Install dependencies
    npm install

    # Start the development server
    npm run dev
   ```
